# Security Policy

This repository contains public research metadata and maintenance scripts; it does not execute the coding agents described by the papers.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow in the repository Security tab. Do not open a public issue for a vulnerability that could affect contributors or downstream users.

Include:

- the affected file and revision;
- a minimal reproduction;
- the expected security impact;
- any suggested mitigation.

Catalog corrections, broken links, and disputed research claims are not security vulnerabilities. Use the issue templates for those reports.

## Supported version

Security fixes apply to the current `main` branch and the latest release.
